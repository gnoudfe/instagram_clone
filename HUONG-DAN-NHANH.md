# Hướng dẫn nhanh cho dự án Instagram Clone

## Cài đặt và chạy dự án

```bash
# Cài đặt dependencies
npm install

# Chạy môi trường phát triển
npm run dev

# Build dự án
npm run build

# Chạy phiên bản production
npm run start
```

## Cấu trúc thư mục chính

- `src/app`: Cấu trúc routing của Next.js App Router
- `src/components`: Các components UI
- `src/services`: Dịch vụ API và React Query
- `src/stores`: State management với Zustand
- `src/pages`: Các trang chức năng

## Quy trình phát triển

1. **Tạo branch mới** cho tính năng cần phát triển
2. **Phát triển tính năng** theo hướng dẫn trong DOCUMENTATION.md
3. **Test kỹ lưỡng** trước khi merge
4. **Merge vào main** và triển khai

## Triển khai nhanh

1. Push code lên GitHub
2. Import dự án vào Vercel
3. Cấu hình biến môi trường (nếu cần)
4. Nhấn Deploy

_Tham khảo tài liệu đầy đủ trong file DOCUMENTATION.md_
